# Security Policy

## Supported Versions

This project is currently under active development. Only the latest version on the `main` branch is supported with security updates.

| Version | Supported |
| ------- | --------- |
| main    | ✅        |
| older commits | ❌  |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

### How to report

- Email: bail.crier4e@icloud.com (Masked iCloud Email)
- Or open a **private security advisory** on GitHub (preferred)

### What to include

Please include as much detail as possible:
- Description of the vulnerability
- Steps to reproduce
- Impact assessment
- Possible fix (if you have one)

### Response expectations

- Initial response within **2–5 days**
- Fix timeline depends on severity and complexity
- You will be notified once the issue is resolved

### Responsible disclosure

Please **do not**:
- Open public issues for security vulnerabilities
- Disclose the issue publicly before it is fixed

We appreciate responsible disclosure to keep users safe.
